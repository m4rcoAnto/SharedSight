Collega iPhone

Nell'app Shared Sight inquadra questo codice: indirizzo, chiave e sessione vengono impostati senza digitarli.

Nessun indirizzo di rete locale trovato: collega questo computer alla stessa rete Wi-Fi degli iPhone.

Il codice contiene la chiave del server: mostralo solo a chi deve collegarsi.
Il server sta eseguendo una versione precedente del codice. Fermalo con Ctrl+C e riavvialo: npm --prefix Server start

In attesa del primo iPhone

Avvia l'app, apri Impostazioni → Stanza 3D e inserisci URL e chiave.
Oppure avvia la simulazione: npm run demo
